1. Data We Collect
Zynmax Vibe collects and processes the following data when used in a Discord server:

User IDs – to associate commands, preferences, and server settings.

Server IDs – to store per-server configuration.

Message content – only when a command is invoked (e.g., !play, !help) or when automated features explicitly require reading message text (e.g., word filters).

Presence data – if enabled, to display user activity (e.g., "Now Playing") in logs or dashboards.

We do not collect email addresses, passwords, or any personal information outside of the data listed above.

2. Why We Collect This Data
To respond to user commands and provide bot functionality.

To maintain server-specific settings and user preferences.

To generate logs requested by server administrators (e.g., join/leave logs, activity tracking).

To enforce server rules (e.g., word filtering, moderation).

3. How We Store and Use Data
Message content and presence data are processed in real-time and not stored after the command or event is handled.

User IDs and server IDs may be stored in a secure database to remember settings, such as custom prefixes, welcome messages, or role assignments.

No data is sold, shared, or disclosed to third parties.

Data is accessible only to the bot owner/operator for maintenance and debugging.

4. User Control and Opt-Out
Users can opt out of presence tracking via Discord’s built-in privacy settings (per-server presence visibility).

Users can avoid message content collection by not using the bot’s commands or by using the bot only in channels where it is disabled.

Users may request deletion of their stored data (e.g., user ID, settings) by contacting the owner via [contact method] or using the /forget command if available.

5. Data Retention
Real-time data (message content, presence) is not retained.

Configuration data (user IDs, server IDs) is retained for as long as the bot is active in the server. If the bot is removed, associated data is automatically deleted after [X days, e.g., 30 days] or upon request.

6. Changes to This Policy
We may update this Privacy Policy from time to time. Users will be notified via the bot’s support server or the /privacy command.
